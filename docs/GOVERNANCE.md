# Governance

Released versions are immutable. Corrections create patch releases and preserve prior manifests through vintage_id and supersedes_id. The protocol becomes locked only when the reviewed commit is tagged before holdout ingestion.

A normalizer extracts atomic claims. A verifier reconstructs each value from the specified first-party locator and checks timestamp basis. A release owner confirms the executable data package, manifest, CI and coverage matrix. Direction labels for production research are blinded and scored for agreement.

Secondary reporting can discover evidence but cannot replace an available primary source. issuer_reported_actual means reported by the issuer rather than independently certified. Forward statements retain their own label.

Use public information only and respect redistribution rights. Every research claim identifies protocol, manifest, universe, price source, execution rule, costs, period and holdout status. Registered falsifiers are reported without post-hoc relabeling.
