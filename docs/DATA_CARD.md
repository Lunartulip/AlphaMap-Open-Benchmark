# Data card

AlphaMap Open Benchmark v1 is a point-in-time reconstruction sample for source audit, pipeline integration and feature replication. It contains six US-listed issuers, eleven first-party documents, twelve events, fifteen observations and two confirmed supplier edges from 2023-08-23 through 2025-03-18.

It is not a statistically powered backtest sample and is marked eligible_for_inference=false in both coverage and manifest metadata. Historical availability is conservatively reconstructed unless wire metadata is explicitly identified. document_sha256 is blank where an immutable publisher artifact was not captured; access and version fields make that limitation machine-visible.

Issuer releases overrepresent management-selected information. Confirmed product relationships do not establish economic exposure. The primary propagation coefficient is therefore a topological research parameter rather than a revenue-share estimate.

Contract validation establishes structural and temporal consistency. It does not independently verify issuer statements or demonstrate predictive performance.
