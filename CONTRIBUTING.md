# Contributing

Evidence contributions require a first-party URL, immutable locator where available, stable identifiers, UTC published/available/tradable timestamps, typed claims, explicit units and a reasoned timestamp policy.

Every pull request must pass contract validation, manifest verification, tests and style checks. A reviewer must be able to reconstruct each normalized value from its locator. Released corrections are append-only.

Do not submit copied article text, broker research, material non-public information or values without redistribution rights.
